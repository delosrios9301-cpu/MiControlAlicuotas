# Mi Control de Alícuotas

Aplicación web personal, independiente de FleboReport y Mi Compra. Publicación estática sin archivos clínicos, datos de pacientes ni capturador local de Excel.

La sincronización con Firebase `mi-control-de-alicuotas-cde8d` requiere configurar la clave web pública de Firebase, Authentication y reglas privadas de Firestore. Hasta entonces los registros se almacenan solo en el dispositivo.

**No introducir datos clínicos reales antes de verificar el acceso privado y la sincronización.**
